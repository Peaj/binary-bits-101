# Binary Bits 101

A minimalist, mobile-first web game for learning binary numbers and bit operations.
Built with React + Vite, Tailwind, and framer-motion.

## Play locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to GitHub Pages
```bash
npm run deploy
```

Publishes to the `gh-pages` branch and serves at:
`https://Peaj.github.io/binary-bits-101/`
